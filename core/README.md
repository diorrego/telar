# core

The framework part of Telar: what every installation shares. It is code, and it is **not defined yet**.

Its structure is being defined in the vault project [`core-definition`](../vault/projects/core-definition/v1/PLAN.md): which non-negotiables Telar enforces in every installation, which mechanisms each project fills with its own values, and what each project repository must provide on its own. Nothing is added here until that project ends in an accepted structure ADR ([ADR 0005](../vault/decisions/0005-documentation-before-code.md), [ADR 0008](../vault/decisions/0008-telar-is-a-method-and-framework.md)).
